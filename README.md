# The InfiniteLimits Website

This is the source code for <https://inflmts.com>.
This project uses [Eleventy](https://www.11ty.dev).

## Getting Started

Install dependencies,
then bring up a development server at <http://localhost:8080>:

```
pnpm install
pnpm dev
```

## Build

```
rm -rf _site
pnpm build
```
